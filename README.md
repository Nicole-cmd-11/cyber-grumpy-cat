# 🐱 赛博打工猫：职场黑话翻译器

> “老板说：这个事儿你牵头，相关同事会配合你。”
> “猫猫翻译：这锅你背，活儿你干，其他人就看着。”

这是一个专治“职场黑话”的 AI 神器。作为一名还没毕业的大学生，为了提前预习职场生存法则，我基于扣子（Coze）工作流与豆包大模型构建了这个翻译器。输入老板的周报、PM 的需求文档，赛博打工猫会为你提供无情的人话翻译与打工人内心 OS。
